# Support

Use GitHub Discussions for setup questions and GitHub Issues for reproducible
bugs or feature requests. Run `.venv/bin/python doctor.py` first and attach its
output after redacting device serials and IP addresses.

For upstream Windows behavior, report to
[DualCPY](https://github.com/theswest/DualCPY). For Linux/X11 behavior, report
to [DualCPY-Linux](https://github.com/DrSkyfaR/DualCPY-Linux).
